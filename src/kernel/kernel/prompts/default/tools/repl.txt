Execute Python code in a per-session REPL worker process. Use this for dense
multi-step investigation and tool orchestration.

Available async helpers include Read, Write, Edit, Glob, Grep, Python, Agent,
Bash, PowerShell, Cmd, plus sh(), cat(), rg(), rgf(), gl(), put(), and chdir().
Only registered tools work. Variables persist while the active REPL worker
lives, but reset after worker timeout, crash, session close, or runtime restart.
Common shorthand forms are supported, for example:
`await Read("path")`, `await Bash("printf hi")`, `await Grep("needle", path="src")`.

REPL code is agent-authored and untrusted. External effects must happen through
the helper tools, which still go through normal DeepCLI permission checks. Do
not use shell commands to stop or restart DeepCLI; use RestartSelf or ask the
user for a kernel restart.

On Windows, sh() defaults to PowerShell. On Linux/WSL, sh() defaults to Bash.
Prefer Read/Write/Edit/Glob/Grep/Python helpers over shell commands for
cross-platform work.
