## Completed Capability Snapshot

### Kernel

- Bootstrap/config/auth: FlagManager, SecretManager, ConfigManager,
  ConnectionAuthenticator.
- Model stack: LLMProviderManager, LLMManager, provider routing, role-based
  `current_used`.
- Protocol/transport/session: ACP stack, WebSocket `/session`, SQLite session
  store, lifecycle actions, mode/config option handling, streaming updates.
- Agent loop: StandardOrchestrator, prompt builder, compaction, plan mode,
  cancellation handling.
- Tools/authz: ToolManager, ToolAuthorizer, BashClassifier, permission
  round-trip, deferred ToolSearch, AskUserQuestion, WebFetch/WebSearch,
  FileRead media support, Todo/Agent/SendMessage tools.
- Extensibility: CommandManager, MCPManager, SkillManager, HookManager,
  MemoryManager, GatewayManager, ScheduleManager, GitManager.
- Control-plane groundwork: `kernel.agents` vocabulary and
  `AgentRuntimeController` protocol.

See [`../kernel/history.md`](../kernel/history.md) for the milestone map and
[`../kernel/subsystems/`](../kernel/subsystems/) for current behavior.

### CLI

- Thin TypeScript/Bun ACP client over WebSocket; no kernel Python imports.
- OMP active-port TUI path with welcome/status/editor, markdown/thinking,
  tool rendering, permission dialogs, session selector, autocomplete, and PTY
  probes.
- ACP-backed session/model/theme/config startup and `/session` / `/model` /
  `/theme` command paths.
- `!` / `!!` shell and `$` / `$$` Python execution routed through kernel ACP
  execution methods.
- Active-port manifest and parity checks guard copied OMP files and local
  assets.

See [`../cli/history/implemented-summary.md`](../cli/history/implemented-summary.md)
for the CLI milestone map.
